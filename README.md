# Flask Docker App 🐳

A simple Flask web application containerized using Docker.

## 🚀 How to Run

### 1. Build the Docker Image 🛠️
```bash
docker build -t my-flask-app .
```

### 💻 2. Run the Container

```bash
  docker run -p 5000:5000 my-flask-app 
'''
Access the app in your browser at:
http://localhost:5000
